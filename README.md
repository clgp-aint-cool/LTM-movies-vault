# LTM Movies Vault 🎬

Curated movie vault and filmography showcase web application built with Next.js 15, React 19, and Tailwind CSS.

## 🚀 Quick Links & Documentation

- [Deployment & CI/CD to Public VM Guide](DEPLOYMENT.md): Step-by-step guide for setting up GitHub Actions CI/CD to deploy on a remote Linux VM.
- [Docker Compose](docker-compose.yml): Production & local container configuration.
- [Application Source Code](site/README.md): Next.js application structure and local development.

## 🐳 Quick Start with Docker

### Local Development / Container Test
```bash
# Build and run locally with Docker Compose
docker compose up --build -d

# Check running status
docker compose ps

# Access application
open http://localhost:80
```
